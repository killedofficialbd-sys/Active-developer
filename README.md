# Active Developer — обновлённое портфолио

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере или разместите папку на статическом хостинге.
3. Для корректной работы геолокации и Clipboard API используйте HTTPS или `localhost`.

## Состав

- `index.html` — интерфейс, стили и JavaScript.
- `favicon.svg`, `favicon-32.png`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — фирменные иконки сайта для браузеров и мобильных устройств.
- `site.webmanifest` — метаданные для установки сайта как веб-приложения.
- `photo_2025-12-15_17-24-12.jpg` — исходное изображение профиля.

Погода работает через Open-Meteo без встроенного API-ключа. Геолокация запрашивается только после нажатия на кнопку. Тема, история команд терминала и последние погодные данные (до 30 минут) сохраняются локально в браузере.
